# SuperStore Sales Analysis Dashboard

## 📊 Project Overview
Analyzed SuperStore sales data using Microsoft Excel to uncover business insights and build an interactive dashboard.

## 🛠️ Tools Used
- Microsoft Excel
- PivotTables & PivotCharts
- Formulas (TEXT, YEAR, IF, SUM, COUNTA)
- Dashboard Design

## 📋 Key Steps
1. **Data Cleaning** (5,900+ rows)
   - Removed extra columns
   - Cleaned Returns column
   - Formatted dates

2. **Feature Engineering**
   - Month column (`=TEXT`)
   - Year column (`=YEAR`)
   - Profit Margin column (`=IF`)

3. **PivotCharts Created**
   - Sales by Category
   - Sales by Region
   - Monthly Sales Trend (Line Chart)
   - Top 10 Products

4. **Dashboard with KPIs**
   - Total Sales: $1,565,804
   - Total Profit: $175,262
   - Total Orders: 3,003

## 💡 Key Insights
- **Technology** is the most profitable category (19% margin)
- **West region** leads in sales ($522K) and profit
- **December** has the highest sales ($244K)
- **Furniture** has the lowest profit margin (2.2%)
